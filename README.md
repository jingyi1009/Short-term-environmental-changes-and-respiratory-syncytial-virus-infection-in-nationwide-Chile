# Short-term-environmental-changes-and-respiratory-syncytial-virus-infection-in-nationwide-Chile
Short-term environmental changes and respiratory syncytial virus infection in nationwide Chile

This repository contains the data and analysis code used in our study on associations between RSV (Respiratory Syncytial Virus) infections and environmental factors across Chile.

## Data
We uploaded the cleaned version of the data analyzed in our study on the **Data** branch.
The `data` folder includes:
1. **Map of Chile**: Shapefile of Chile (cl_shp).
2. **Region Coordinates**: CSV file (Lonlat) containing the longitude and latitude of 16 Chilean regions.
3. **Environmental Data**: CSV file with regional environmental factors of Chile.
4. **RSV Data**: Access can be obtained by contacting the Public Health Institute of Chile, contact email: rfasce@ispch.cl.

## Research Content
We provide demonstrations of our research on the **Analysis** branch.
### 1. Main Analyses
1.1 **Descriptive Analysis**
Descriptive analysis was performed using the demo data, focusing on spatial and temporal trends of RSV infections and quantifying the seasonality of RSV epidemics.

1.2 **Statistical Models**
Regression analyses examining associations between RSV infections and environmental factors.

1.3 **Subgroup Analyses**
Includes detailed results from subgroup analyses conducted across different geographical groups.

### 2. Sensitivity Analyses
Contains information on the sensitivity analyses we performed to validate the robustness of our findings.
